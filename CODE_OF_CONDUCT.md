# Code of conduct

Treat contributors and users with respect. Welcome differing expertise and backgrounds. Give specific, constructive technical feedback and assume good intent when asking for clarification.

Harassment, discriminatory remarks, threats, sexualized conduct, doxxing and disclosure of private information are not acceptable. Do not post proprietary data or credentials in issues or discussions.

Maintainers may edit or remove harmful content, warn participants, temporarily restrict participation or permanently ban repeated or severe misconduct. Apply these decisions consistently and explain them privately when appropriate. Report concerns privately to the repository owner through the GitHub profile contact options. Do not create a public issue containing sensitive details. Maintainers must recuse themselves from handling complaints about their own conduct.
